# 项目经历

## 门店运营中台 · 排班与库存

2024.06 — 至今 · 模块主要开发

Vue 3 · TypeScript · Vite · Naive UI · Pinia · i18next

连锁门店的排班和库存流程。店长提交排班，区域审核后再下发；调拨单在不同状态下，同一张表里能改的字段不一样。系统是微前端，我的工作在业务子应用里。

- 按单据状态和当前处理人控制字段可编辑或只读。页面只读时不挂校验规则，避免按钮隐藏以后，单元格和必填校验还在生效。
- 驳回给发起人时恢复基本信息的必填；完成情况是否可编辑按状态单独判断，不和普通审批共用一套规则。
- 列表筛选和提交使用字典编码，页面只显示文案，避免用中文去比对接口数据导致筛选为空。
- 导出时去掉未选择的筛选条件。排班日期禁止选今天之前，当天可选，开始和结束可以是同一天。
- 新建和审批拆成不同页面，附件和基本信息拆成子组件。重复提交时，接口返回已存在则直接打开查看页。
- 同一时期还负责库存盘点的主要页面，包括盘点结论切换时清空残留值，以及自动带出的结论不允许手改。
- 封装门店树选择、级联选择、表格工具栏和带编辑弹窗的输入框，并维护仓库与供应商的选择弹窗。附件上传由我后期主要修改。
- 调整本地联调的启动方式和端口。外部系统嵌入时隐藏侧边栏，首页增加意见反馈入口，并调整语言编码和按钮权限的挂载位置。
